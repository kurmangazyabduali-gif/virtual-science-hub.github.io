# Запуск AI-редактора презентаций

Для того чтобы локально запустить сервер и безопасно использовать ключи от Gemini AI, вам необходимо:

1. **Установить Node.js**
   Скачайте и установите Node.js с официального сайта: [nodejs.org](https://nodejs.org/)

2. **Установить зависимости**
   Откройте терминал (PowerShell или Командную строку) в папке проекта и выполните команду:
   ```bash
   npm install
   ```

3. **Запустить сервер**
   Выполните команду:
   ```bash
   npm start
   ```

4. **Открыть в браузере**
   Перейдите по ссылке: [http://localhost:3000/presentation.html](http://localhost:3000/presentation.html)

## Почему нужен сервер?
Браузерные скрипты (Vanilla JS) могут быть легко просмотрены любым пользователем. Если бы мы добавили ваш ключ от Google Gemini напрямую в клиентский JS-код, кто угодно мог бы скопировать его и использовать за ваш счет.
Запуск локального сервера (через `server.js`) позволяет скрыть ключ в файле `.env.local` и общаться с ИИ через защищенный API `/api/gemini`.
